适用于 B 站原页可以读取的独立音轨。无需安装扩展；这是一条需要手动运行脚本的备用方式。

  1. 在原站打开视频。

    等播放器加载完成，不必播放完整视频。

    打开 B 站原视频 ↗
  2. 在原页运行获取脚本。

    复制后，在 B 站页面的开发者工具 → Console 中运行。只读取播放器中的音轨地址，不读取或导出 Cookie。

    查看脚本
  3. 导入下载的音频。

    原页显示进度，点击"保存音轨"下载 M4A 文件。回这里选择文件，本机转写完成后再生成文章。

不保证受限视频可用。音频不上传转写服务；只有生成文章时，文字才发送给你配置的模型服务。

连接你的模型

填入自己的 API。字幕只会在你生成内容时发送给所选服务。

不会写入浏览器存储、项目文件或导出文章。

高级设置

仅向视频服务发送链接和字幕语言；音轨由你的浏览器直接下载，转写仍在本机。模型 Key 不发送给视频服务。

只保存服务地址、模型和语言偏好。Key 不落盘，刷新页面后需要重新填写。长字幕会分段生成，可能产生多次 API 调用。

打开网页，就开始。

无需安装 Python、yt-dlp 或本地模型服务。桌面 Chrome / Edge 是首版推荐的音频授权浏览器。

  1. 贴链接，先读字幕

    选择文章篇幅，网页先尝试读取可访问的字幕。

  2. 按需授权音频

    字幕无法读取时，打开原视频，授权共享该标签页音频，从起点播放。

  3. 完成转写，整理文章

    停止后处理剩余队列，再用自己的 API 生成文章，复制或导出全文。

使用之前，你可能想知道。

这个网页就是应用吗？

是。点击开始使用即可进入真实纯前端应用，无需本机服务。中文界面支持生成中文和英文文章，也提供中英文产品介绍。

为什么有时需要共享视频标签页音频？

普通网页无法任意读取其他网站的受保护音轨或字幕。授权共享的是播放中的音频；转写随播放进度进行，不是瞬间下载整段音轨。暂停、跳转、广告、倍速会影响时间点，跳过的内容无法补齐。

无 GPU 会很慢吗？

可使用 CPU / WASM 的轻量 Whisper tiny 模型，速度取决于设备。慢设备会显示积压时长，停止采集后继续处理。GPU 只是可选加速，不是使用门槛。

ASR、模型和文章是否免费？

本地浏览器 ASR 不调用收费转写服务。首次需要下载开源模型；文章使用你配置的 API，费用或免费额度由服务商决定。自定义服务需支持浏览器 CORS，不内置共享 Key。

识别失败后怎么办？

已识别文本和待处理音频会保留，可用 CPU 重试或下载待处理音频。未完成的结果会标注状态。文章纠错不等于外部事实核查，关键事实仍需回看来源。

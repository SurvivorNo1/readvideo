一个页面，三件事。

先拿到来源，再整理内容。阅读的每一步，都能回到原文。

01 / EXTRACT

完整字幕，保留时间。

通过 yt-dlp 获取所选字幕轨道的完整内容，人工字幕或自动字幕均可。搜索、复制和导出全文；提取字幕不需要模型 API。

02 / READ

按你的时间，选择篇幅。

速读摘要，或短篇、中篇、长篇、详细文章。按素材密度组织观点、论据和例子，点击时间点回到视频，导出 Markdown 留存。

03 / REFINE

校订表达，尊重事实。

根据上下文纠正明显转写错误和断句。人名、术语、数字不凭猜测修改；不确定之处标注存疑，重要校订附说明，原字幕保留。

同一份内容，四种阅读深度。

篇幅是目标，内容是依据。字幕简短时会适当缩短，不为凑字数编造。

短篇约 300–500 字
抓住核心结论
中篇约 800–1,500 字
理解主要观点和论据
长篇约 1,800–3,000 字
展开例子与推理
详细约 3,000–5,000 字
梳理过程、证据和限制

在你的电脑上，开始阅读。

需要 Python 3.10 或更新版本，以及可连接视频平台的网络。Windows 下载仓库后，双击 run.bat 即可安装依赖并打开界面。

下载源码 ZIP完整安装说明 ↗
  1. 启动本机应用

    下载并解压，Windows 双击 run.bat；macOS、Linux 按仓库说明启动。

  2. 选择自己的 API

    打开右上角 API 配置，填写 DeepSeek、Gemini 或兼容接口的 Key，测试连接。

  3. 粘贴链接，选择篇幅

    生成文章，或仅获取完整字幕。没有可用字幕时，也可以导入 SRT / VTT。

git clone https://github.com/SurvivorNo1/readvideo.git
cd readvideo
python -m venv .venv
# Windows:
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py --open-browser

API Key 仅保存在当前运行内存，不写入浏览器持久存储。点击生成时，字幕会发送给你选择的模型服务商。

使用之前，你可能想知道。

这个网页能直接处理视频吗？

不能。GitHub Pages 展示产品与安装说明；实际提取需要本机 Python 和 yt-dlp。启动后在本机浏览器操作，无需额外注册账号。

没有字幕的视频也能用吗？

目前读取平台已有的完整字幕轨道，不下载音视频，也不做语音转写。受登录、地区、平台限制时会提示失败；可导入你已有的字幕文件。

可以用免费的模型 API 吗？

可以自行配置提供免费额度的兼容服务；Gemini 是一个可选配置。额度、地区和模型可用性由服务商决定。DeepSeek 并不默认免费。本项目没有内置公共 Key，也不使用 Ollama。

纠错是否等于事实核查？

不等于。纠错针对字幕转写和表达中的明显问题。应用没有外部事实检索，无法保证讲者的每个观点或数据正确；不确定内容会要求模型保留并标注，关键事实仍应核对来源。

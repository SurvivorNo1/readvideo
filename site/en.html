01 / EXTRACT

Every cue. Original timestamps.

Use yt-dlp to retrieve the complete selected caption track, authored or automatic. Search, copy and export the full transcript. Caption extraction needs no LLM key.

02 / READ

Choose your reading depth.

Get a quick summary or a short, medium, long or detailed article. Follow the source's arguments and examples, revisit timestamps, and export Markdown.

03 / REFINE

Edit carefully. Keep the evidence.

Correct clear transcription and punctuation errors using context. Flag uncertain names and terms instead of guessing. Preserve numbers, attribution and the original captions.

    Open API settings. Choose DeepSeek, Gemini or a compatible endpoint, enter your key and test the connection.

    Generate an article or just extract the captions. Import SRT / VTT files when platform access is restricted.

Keys remain in runtime memory, not persistent browser storage. When you request generation, captions are sent to the API provider you select. The app interface is currently Chinese; generated content supports Chinese and English.

A few things to know.

Can this website process a video directly?

No. GitHub Pages hosts this product website. Extraction requires the local Python app and yt-dlp. Once started, the app opens in your browser without an extra account.

What if the video has no captions?

The app retrieves an existing complete caption track. It does not download media or transcribe speech. Login requirements, regional limits or platform blocking may prevent extraction. You can import an existing subtitle file instead.

Can I use a free API?

You can configure a compatible service that offers a free tier, such as an eligible Gemini API account. Quotas, regions and model availability depend on the provider. DeepSeek is not assumed to be free. There are no bundled shared keys and no Ollama dependency.

Does correction mean fact checking?

No. Editorial correction addresses clear caption and expression errors. There is no external fact retrieval, so it cannot verify every claim a speaker makes. Uncertain content is flagged by instruction; important claims still need source verification.
